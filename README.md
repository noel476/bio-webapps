# 生物基礎 インタラクティブ教材(bio-webapps)

高校「生物基礎」のオンデマンド授業・授業内活動で使える、**ブラウザだけで動く小さな教材集**です。
インストール・ログイン・ビルド不要、外部ライブラリ・CDN・外部通信なし。各教材は**単独の `.html` ファイル**で動きます(ダブルクリックで開けます)。

- 入口: [`index.html`](index.html)(教材一覧・カード形式)
- 日本語UI / スマホ(幅375px)とPCの両対応 / ライト・ダーク両対応(右上のボタンで切替)
- 色だけに頼らない表示(線種・形・記号・文字を併用)/ キーボード操作に配慮
- **生徒の個人情報は扱いません。入力内容の保存・サーバ通信は一切行いません**(`localStorage` 等も不使用。静的テストで確認済み)

## 各教材の概要

### 1. 体細胞分裂のステップ送り(`mitosis.html`)
- **概要**: G1期→S期→G2期→前期→中期→後期→終期→娘細胞の8段階を、染色体(2n=4の模式図)のアニメーションで表示。細胞1個あたりのDNA量グラフ(◆が現在位置)、染色体数・DNA量の一覧表が連動します。
- **使い方**: 「次へ/前へ」ボタン、時期ボタン、キーボードの ← → キー、「自動再生」で進めます。「動物細胞/植物細胞」の切替で、中心体・細胞質分裂(くびれ/細胞板)の違いを比べられます。最後に確認クイズ。
- **ねらい**: 後期に染色体数が一時的に2倍(8本)に数えられること、DNA量は4→2(細胞1個あたり)に戻ることを、図とグラフの両方で結びつける。
- **既知の制限**: 染色体は4本(2n=4)の模式図で、実際の整然さ・形とは異なります。各時期の長さはグラフ上で目安(M期は実際には間期よりずっと短い)。動物細胞の細胞質分裂は終期にまとめて描画。減数分裂は対象外。
- **改善案**: 顕微鏡写真(タマネギ根端)との対応クイズ、細胞周期の時間割合の可視化、減数分裂版。

### 2. 浸透圧と細胞の変化(`osmosis.html`)
- **概要**: 外液の濃度スライダーで、赤血球(食塩水)の膨張・溶血・収縮(金平糖状)と、植物細胞(ショ糖液)の吸水(膨圧)・限界原形質分離・原形質分離を表示。水の分子(○)と溶質(●)の動き、体積グラフ(◆が現在位置)付き。
- **使い方**: 「赤血球/植物細胞」を選び、スライダーまたはプリセットボタンで濃度を変えます。
- **ねらい**: 水は濃度の低い側から高い側へ動く/細胞膜は水を通すが溶質は通しにくい/細胞壁の有無で結果が違う、を一続きで理解する。
- **既知の制限**: 水の出入りだけを考えた単純なモデル(ボイル・ファントホッフ型)。赤血球は約0.9%で等張・約0.45%以下で溶血、植物細胞は細胞液がショ糖0.35 mol/L相当、という**例**の数値です(実際は細胞の種類・状態で異なります)。粒子の位置は乱数で固定した模式図です。
- **改善案**: 実験の写真・動画との対応、浸透圧(吸水力)の計算問題、「半透膜つきU字管」版。

### 3. 光合成と呼吸の速度グラフ(`photosynthesis.html`)
- **概要**: 光の強さ・CO₂濃度・温度のスライダーで、光合成速度(総)・呼吸速度・見かけの光合成速度の曲線を描画。横軸を「光/CO₂/温度」から選べ、光補償点・光飽和点・現在の限定要因を表示。陽生植物/陰生植物の切替、葉でのCO₂の出入りの図付き。
- **使い方**: 横軸を選び、条件を動かして曲線の変化を観察。◆がいまの条件の位置です。
- **ねらい**: 「見かけの光合成速度 = 光合成速度 − 呼吸速度」を読み取れるようにし、光補償点・光飽和点・限定要因の意味を自分で見つけられるようにする。
- **既知の制限**: 学習用の**模式モデルの計算値**で、実測値ではありません(単位は相対値)。光飽和点は「最大値の95%に達する光の強さ」という目安の定義。限定要因の判定は簡易的で、実際には複数の要因が同時に影響します。C4植物・CAM植物、強光障害は対象外。
- **改善案**: 実験データの入力・グラフ読み取りワークシート、昼夜の変化(1日の物質収支)。

### 4. 酵素反応と反応速度(`enzyme.html`)
- **概要**: 酵素の種類(だ液アミラーゼ・ペプシン・トリプシン・カタラーゼ・好熱菌の酵素)を選び、酵素量・基質濃度・温度・pHを変えて、粒子の動き(基質▲と生成物●●、酵素の活性部位)と反応速度グラフを確認。
- **使い方**: 「やってみよう」: ①70℃まで上げて最適温度へ戻す(戻らない=失活は不可逆) → ②「酵素液を新しくする」→ ③0℃まで下げて戻す(戻る=低温は失活ではない)。
- **ねらい**: 基質濃度の曲線は「頭打ち(酵素が飽和)」、温度・pHは「最適値で最大の山形」という形の違いと理由、および失活の不可逆性の理解。
- **既知の制限**: 粒子の動きは速度の計算式にしたがう**イメージ**で、基質は減らない(初速度の測定に相当)。失活は「過去にさらされた最大の高温」で単純化(実際は加熱時間にも依存)。極端なpHでの失活、阻害剤、補酵素は対象外。
- **改善案**: 競争的阻害・補酵素の追加、実験(カタラーゼ+肝臓片)のシミュレーション。

### 5. 遺伝の基本(1遺伝子の交雑)(`genetics.html`)
- **概要**: 形質(エンドウの種子の形・子葉の色・花の色)と親の遺伝子型を選び、パンネット方形・遺伝子型と表現型の比を表示。交雑シミュレーション(1〜1000個体ずつ、理論値◇と比較)、検定交雑ゲーム(見えない遺伝子型を推理)付き。
- **使い方**: ①パンネット方形(プリセットボタンあり) → ②交雑シミュレーション → ③検定交雑ゲーム(子が潜性なら必ずヘテロ。少数だと偶然見逃す確率 (1/2)ⁿ を表示)。
- **ねらい**: 比は「確率」であり、個体数が少ないとずれること。遺伝子型は見た目から分からず、検定交雑で推理できること。
- **既知の制限**: 1遺伝子・完全顕性(優性)のみ。不完全優性・独立の法則(二遺伝子)・連鎖・伴性遺伝は対象外。用語は「顕性(優性)/潜性(劣性)」を併記。
- **改善案**: 二遺伝子雑種、不完全優性(オシロイバナ)、家系図の問題。

### 6. DNAからタンパク質へ(`dna.html`)
- **概要**: DNAの鋳型鎖の塩基配列を入力/選択すると、相補鎖・mRNA・アミノ酸の並びを1コドンずつ表示。塩基の置換・挿入・欠失で突然変異(同義・ミスセンス・ナンセンス・フレームシフト)の影響を比較できます。鎌状赤血球貧血(GAG→GUG)の例、塩基の割合(シャルガフの規則)の演習、遺伝暗号表付き。
- **使い方**: 例ボタンで配列を読み込み、鋳型鎖の塩基をタップして選び、置換・挿入・欠失ボタンで変異を入れ、変異前後のアミノ酸を比べます。
- **ねらい**: 「DNA→(転写)→mRNA→(翻訳)→タンパク質」の流れと、1塩基の変化がタンパク質に与える影響を体験する。
- **既知の制限**: DNAの向き(5′→3′)・イントロン除去・開始コドンの前後の調節配列などは省略。ヘモグロビンの配列は実際の遺伝子の冒頭付近を**模して簡略化**した例。翻訳は最初のAUGから開始。入力は60塩基まで。標準遺伝暗号表のみ。
- **改善案**: 転写・翻訳のアニメーション、ゲノム編集・PCRへの発展、遺伝暗号表を隠した暗記テスト。

### 7. 血糖値の調節(`glucose.html`)
- **概要**: 食事(炭水化物量)・運動・インスリン注射・体質(健康/1型/2型糖尿病)を選び、6時間の血糖濃度・インスリン・グルカゴンの変化をグラフ表示。スライダーで時刻を動かすと、いま「血糖を下げる側」「上げる側」のどちらの調節がはたらいているかが強調されます。
- **使い方**: 時刻スライダーを動かすか「再生」。「血糖値が最大の時点へ」ボタンも使えます。
- **ねらい**: 負のフィードバックによる血糖濃度の一定化、インスリンとグルカゴンの拮抗、糖尿病で何が変わるか(1型=分泌不足、2型=分泌低下・効きにくさ)の理解。
- **既知の制限**: **学習用の簡単な計算モデルで、実際の人の血糖値・診断・治療には使えません**。アドレナリン・糖質コルチコイドは図と説明のみで計算にはグルカゴンで代表させています。食事の消化吸収、インスリンの種類、低血糖症状などは省略。
- **改善案**: 腎臓の再吸収(尿糖)、グリコーゲンの貯蔵量の可視化、食事内容(GI値)の違い。

## クイズ機能(共通)
- 各教材の最後に4択クイズ。1問ずつ回答→○/×と解説→次へ→最後に採点とまちがえた問題の一覧→再挑戦(選択肢の並びは毎回シャッフル)。
- 問題は**各教材ファイルの中のデータ**(`const QUIZ = [...]`)です。`{ q, choices[4], answer(0〜3), explain }` の形式で、**生成後のHTMLを直接編集して問題を差し替えることもできます**(ビルド不要で動くため)。
- 回答内容は保存・送信されません(ページを閉じると消えます)。

## 公開・配布のしかた
- 各`.html`は単独で動くので、**ファイルを共有フォルダやLMSに置いて配布**する、またはフォルダごとWebサーバに置くだけで使えます。
- GitHub Pagesで公開する場合は、このフォルダ(`bio-webapps/`)をサイトのルート(または`docs/`など公開対象)に置いてください。ブランチのルートを公開元にしている場合は `…/bio-webapps/` で開けます。(※このリポジトリでGitHub Pagesの公開までは確認していません。)

## 開発メモ(編集・再生成・テスト)
```bash
node bio-webapps/build.mjs                  # _src/ から *.html と index.html を再生成
node --test bio-webapps/tests/*.test.mjs    # ロジック・静的チェック・配色コントラストのテスト
node bio-webapps/tests/quiz-ui.mjs          # 全教材のクイズをブラウザで最後まで操作して検証(要 Playwright)
node bio-webapps/tests/other-ui.mjs         # 体細胞分裂・浸透圧・光合成のUI操作テスト(要 Playwright)
node bio-webapps/tests/enzyme-ui.mjs        # 酵素(同様に genetics-ui / dna-ui / glucose-ui もあります)
node bio-webapps/tests/smoke.mjs mitosis.html /tmp/shots   # 375px/1280px × ライト/ダークで撮影・横スクロール/エラー検査
```
- `_src/common.css`・`_src/common.js` が共通部分、`_src/lessons/<id>/` が各教材(`meta.json`・`body.html`・`style.css`・`logic.js`・`quiz.js`・`ui.js`)です。`logic.js` は画面に依存しない純粋なロジックで、Node単体でテストできます。
- 新しい教材は `_src/lessons/<id>/` を追加して `build.mjs` を実行すれば、一覧に自動で載ります。
- 生成された `*.html` は自動生成ファイルです。長期的に編集する場合は `_src/` 側を直し、再生成してください。
