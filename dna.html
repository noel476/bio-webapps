DNAからタンパク質へ(転写・翻訳)

ねらい: DNAの塩基配列が、転写でmRNAに、翻訳でアミノ酸の並び(タンパク質)に写される流れを1文字ずつたどります。塩基を変えて突然変異の影響も調べましょう。

① DNAの配列(転写の鋳型になる鎖)を用意する

A・T・G・C 以外の文字は自動で取り除かれます。最大60塩基。mRNAのAUG(開始コドン)から翻訳が始まります。

② 転写と翻訳をたどる

DNAの鋳型鎖の塩基をタップすると、その位置を選べます。表は横にスクロールできます。

転写: 鋳型鎖の A→U、T→A、G→C、C→G でmRNAができる 翻訳: mRNAの3塩基(コドン)が1つのアミノ酸を指定する

mRNAの塩基配列は、鋳型にならなかったほうのDNA鎖(相補鎖)の配列の T を U に変えたものと同じです。

③ 突然変異を起こしてみる

鋳型鎖の塩基をタップして、変えたい位置を選んでください。

④ 塩基の割合の練習(シャルガフの規則)

二本鎖DNAでは、A と T の割合が等しく、G と C の割合が等しくなります(A=T、G=C)。4つの塩基の割合の合計は100%です。

正解数: 0 / 0

RNA(一本鎖)では、A=U のような関係は一般には成り立ちません。この規則が成り立つのは、塩基が対になる二本鎖DNAです。
