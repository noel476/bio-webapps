生物基礎 インタラクティブ教材

ブラウザだけで動く小さな教材集です。スライダーやボタンを動かして、しくみを目で確かめられます。各教材の最後に4択の確認クイズがあります。インストールやログインは不要で、入力内容の保存や外部への送信は行いません。

🔬

体細胞分裂のステップ送り

間期から分裂期までを1段階ずつ送り、染色体の動きとDNA量の変化を同時に確かめます。動物細胞と植物細胞の違いも比べられます。 対応: 細胞周期・体細胞分裂・DNAの複製 / 所要 約15分 開く → 💧

浸透圧と細胞の変化

外液の濃度をスライダーで変え、赤血球の膨張・溶血・収縮と、植物細胞の吸水・原形質分離を観察します。水と溶質の動きも見られます。 対応: 浸透・半透膜・細胞膜・原形質分離 / 所要 約15分 開く → 🌿

光合成と呼吸の速度グラフ

光の強さ・CO₂濃度・温度を変えて見かけの光合成速度を描き、光補償点・光飽和点・限定要因を読み取ります。陽生植物と陰生植物も比べられます。 対応: 光合成と呼吸・光補償点・光飽和点・限定要因 / 所要 約20分 開く → ⚗️

酵素反応と反応速度

基質濃度・酵素量・温度・pHを変えて反応速度のグラフを描きます。基質と酵素の粒子の動きや、高温での失活(元に戻らない)も確かめられます。 対応: 酵素のはたらき・基質特異性・最適温度・最適pH / 所要 約20分 開く → 🌱

遺伝の基本(1遺伝子の交雑)

親の遺伝子型を選んでパンネット方形を作り、分離比を確かめます。交雑のシミュレーションと、検定交雑で遺伝子型を当てるゲーム付きです。 対応: 遺伝子型と表現型・分離の法則・検定交雑 / 所要 約20分 開く → 🧬

DNAからタンパク質へ(転写・翻訳)

DNAの塩基配列からmRNA、アミノ酸への流れを1文字ずつたどります。塩基の置換や挿入・欠失(突然変異)の影響や、鎌状赤血球貧血の例、塩基の割合(シャルガフの規則)の演習もできます。 対応: DNAの構造・転写と翻訳・遺伝暗号・突然変異 / 所要 約25分 開く → 🩸

血糖値の調節(ホメオスタシス)

食事や運動で血糖値がどう変わり、インスリン・グルカゴンなどのはたらきでどう保たれるかを、時間を動かしながら観察します。糖尿病のしくみも比べられます。 対応: 体内環境の維持・ホルモンによる調節・フィードバック・糖尿病 / 所要 約25分 開く →
